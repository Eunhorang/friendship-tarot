# 두근두근! 우정 타로!

> 오늘 우리 우정에는 어떤 마법이 숨어 있을까?

친구 사랑의 날 부스에서 태블릿으로 쓰는 우정 타로 카드 체험 앱이에요. 2~4명이 차례로 카드를 뽑아 카드의 뜻을 읽고, 카드에 숨은 우정 미션을 서로에게 한 다음, 오늘의 우정 운세를 함께 확인해요. 운세에는 좋은 말만 나와요.

## 체험 순서

1. **인원 고르기**: 첫 화면에서 2명, 3명, 4명 가운데 하나를 눌러요.
2. **이름 적기**: 이름이나 별명을 적어요. 비워 두면 토끼·곰돌이·고양이·병아리 친구로 불러요.
3. **카드 뽑기**: 12장 가운데 한 명씩 한 장을 골라요. 카드가 앞으로 나와 빙글 뒤집히면서 이름과 상징 그림이 나타나고, 상징과 뜻을 읽어 줘요. 고르기 전에 `카드 섞기`로 남은 카드를 섞을 수도 있어요.
4. **우정 미션**: 모두 뽑으면 카드마다 숨은 미션이 하나씩 열려요. 미션은 다음 차례 친구에게 하고, 마지막 친구는 첫 친구에게 해요. 부끄러워하는 친구는 `쉬운 미션으로 바꾸기`를 누르면 되고, 넘어가도 괜찮아요. 미션을 할 때마다 우정 온도가 올라가요.
5. **우정 운세**: 수정 구슬이 카드의 마법을 모은 뒤 결과가 나와요. 팀 이름, 종합 운세, 우정 에너지, 행운 쪽지, 친구별 운세와 약속, 그리고 다 함께 외치는 우정 주문까지 이어져요.

## 카드 12장

카드마다 별·하트 문양과 고유한 상징 그림이 들어 있어요. 마법은 네 가지(별·하트·달·햇살)이고, 마법마다 카드가 세 장씩이에요.

| 번호 | 카드 | 마법 | 뜻 | 미션 |
| --- | --- | --- | --- | --- |
| I | 소원 별똥별 | 별 | 꿈 응원 | 꿈 응원단 출동! |
| II | 칭찬 왕관 | 별 | 칭찬 | 칭찬 왕관 씌워 주기 |
| III | 우정 별자리 | 별 | 함께 빛나기 | 우리만의 별자리 이름 짓기(모두 함께) |
| IV | 나눔 쿠키 | 하트 | 나눔 | 좋아하는 것 나누기 |
| V | 마음 편지 | 하트 | 고마운 마음 | 말로 쓰는 편지 |
| VI | 함께 우산 | 하트 | 도움 | 도움 우산 펼치기 |
| VII | 귀 기울이는 달 | 달 | 귀 기울이기 | 30초 귀 기울이기(타이머) |
| VIII | 달빛 등불 | 달 | 힘내라 응원 | 힘내라 마법 주문 |
| IX | 약속 팔찌 | 달 | 믿음 | 새끼손가락 우정 약속 |
| X | 웃음 햇님 | 햇살 | 웃음 | 1분 안에 웃음 폭탄(타이머) |
| XI | 무지개 다리 | 햇살 | 서로 다름 | 닮은 점, 다른 점 찾기 |
| XII | 두근 풍선 | 햇살 | 함께 놀기 | 우정 포즈 3, 2, 1!(모두 함께) |

종합 운세는 뽑힌 카드의 마법을 세어서 정해요. 한 마법이 가장 많으면 그 마법의 팀(예: 포근포근 달빛 공감단), 두 마법이 똑같이 많으면 두 마법을 합친 팀(예: 밤하늘 별달 팀), 모두 다르면 알록달록 무지개 우정단이 돼요. 팀은 모두 11가지이고 팀마다 운세 문장과 우정 주문이 따로 있어요.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 뼈대 |
| `css/style.css` | 색, 카드 모양, 뒤집기·반짝이 움직임, 가로·세로 화면 배치 |
| `js/cards.js` | **카드 12장의 이름·상징·뜻·미션·운세, 팀 운세와 주문, 행운 쪽지 목록** |
| `js/art.js` | 카드 상징 그림, 카드 뒷면, 동물 표시, 수정 구슬(모두 SVG로 그려서 그림 파일이 없어요) |
| `js/sound.js` | 효과음(소리 파일 없이 Web Audio로 만들어요) |
| `js/app.js` | 화면 흐름과 운세 계산 |
| `sw.js` | 한 번 열어 둔 뒤에는 인터넷이 끊겨도 열리게 해 주는 서비스 워커 |
| `manifest.webmanifest`, `icons/` | 홈 화면 아이콘과 앱 이름 |

## 문구 고치기

카드 이름, 미션, 운세 문장은 모두 `js/cards.js`에 있어요. 미션 문장의 `{to}`는 미션을 받는 친구 이름, `{me}`는 카드를 뽑은 친구 이름으로 바뀌어요. `{to|이/가}`처럼 쓰면 이름 받침에 맞춰 조사를 골라 붙여요(받침 있을 때/없을 때 순서로 `이/가`, `은/는`, `을/를`, `과/와`).

## 내 컴퓨터에서 미리 보기

```bash
python3 -m http.server 4340 --directory friendship-tarot
```

그다음 브라우저에서 `http://localhost:4340`을 열어요. `index.html`을 더블클릭해서 열어도 화면은 나오지만, 오프라인 저장 기능은 주소로 열었을 때만 동작해요.

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만들어요(예: `friendship-tarot`, 공개 저장소).
2. 이 폴더를 저장소에 올려요.

   ```bash
   cd friendship-tarot
   git init -b main
   git add .
   git commit -m "두근두근! 우정 타로! 첫 버전"
   git remote add origin https://github.com/<아이디>/friendship-tarot.git
   git push -u origin main
   ```

3. 저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, 브랜치를 **main / (root)**로 고르고 저장해요.
4. 1~2분 뒤 `https://<아이디>.github.io/friendship-tarot/`에서 열려요.

파일을 고쳐 다시 올릴 때는 `sw.js` 맨 위 `CACHE` 이름 끝 숫자(`v1` → `v2`)를 올려 주세요. 그래야 이미 한 번 열어 둔 태블릿도 새 파일을 받아요.

## 부스 운영 팁

- **홈 화면에 추가**하면 주소창 없이 앱처럼 열려요. 아이패드는 Safari 공유 버튼 → 홈 화면에 추가, 갤럭시 탭은 Chrome 메뉴 → 홈 화면에 추가를 쓰면 돼요.
- 행사 전에 부스 태블릿으로 **한 번 끝까지 체험**해 두세요. 화면과 글꼴이 저장돼서 당일 와이파이가 끊겨도 돌아가요.
- 체험 중에는 화면이 저절로 꺼지지 않게 막아요(지원하는 브라우저에서만).
- 오른쪽 위 버튼으로 도우미 안내 보기, 소리 켜고 끄기, 전체 화면을 쓸 수 있어요. 왼쪽 위 집 모양 버튼은 처음 화면으로 돌아가요.
- 이름은 화면에만 잠깐 쓰이고 어디에도 저장하거나 보내지 않아요.
